# Portfolio design direction

Use the installed UI/UX Pro Max skill's portfolio design-system search and React accessibility guidance. The search returned an asymmetric, high-contrast portfolio with Archivo headings and Space Grotesk body type. Adapt its blue recommendation to the user's explicit red and green accents. Use semantic anchors and buttons, 44px controls, visible keyboard focus and reduced-motion support.

Palette: paper #f5f6f3, ink #18271f, green #246348, red #b83e32, muted #5c6861, line #d7ddd6. White panels give the project sketches clarity. Red marks actions and small identity details; green carries the typography and spatial diagrams. Neither color alone conveys status.

Layout: a spacious, left-aligned workspace. Large typographic introduction, a compact personal introduction, and an interactive project sketch. Below it, project case summaries with individual visual diagrams, then chronological experience, education/research, and direct contact. Avoid stock office photography, aurora backgrounds, typing loops, WebGL overhead, fake product metrics, repeated glass cards and magnetic cursors.

The initial generic brutalist grid recommendation was revised: rounded application windows belong to Along's subject, but the reading layout stays quiet. The interactive workspace is the memorable element; the rest prioritizes actual project evidence.
